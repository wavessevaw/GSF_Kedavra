# Detail lab

These are development/benchmark tools, not runtime dependencies. `make detail-lab`
builds an additional `kfg_detailtest` and a `build/research/` shader set containing
the adapted RCAS comparator. Production `kfg_posttest` and Gamescope exclude RCAS.

```sh
make -C kedavra all detail-lab
python3 -m pip install numpy scipy Pillow
python3 kedavra/tools/detail/fetch_references.py /tmp/detail-references
mkdir -p /tmp/detail-fg
KFG_HARD_OUT=/tmp/detail-fg KFG_HARD_X2=1 KFG_DETAIL_SEQUENCE_OUT=/tmp/detail-fg \
  kedavra/build/kfg_vktest --spv kedavra/build --size 320x200 --hard \
  --json /tmp/detail-fg-engine.json
python3 kedavra/tools/detail/compare.py --exe kedavra/build/kfg_detailtest \
  --spv kedavra/build/research --references /tmp/detail-references \
  --fg /tmp/detail-fg --out /tmp/detail-results --bench 100
```

Install ffmpeg for the video output. Run the full engine regression separately at
its standard resolution with `make -C kedavra test`. The small 320×200 hard sequences
are diagnostic stress proxies, not Steam Deck performance measurements or game captures.
Use `KFG_VALIDATION=1` when the Khronos Vulkan validation layer is installed.

`bench_detail.py` uses only Python standard library and the compiled executables;
it runs independently on Steam Deck without Python scientific dependencies. Its
timestamps exclude test upload/readback. See `docs/detail/DECK-VALIDATION.md` for
the full compositor and frame-pacing gates.

## Image provenance

Inputs are downloaded from scikit-image **v0.25.2**, verified against `references.json`.
Source attribution is documented in that revision's `skimage/data/_fetchers.py`:

- `astronaut.png`: NASA portrait of Eileen Collins; public domain, no known restrictions.
- `chelsea.png`: Stefan van der Walt; CC0.
- `brick.png`: CC0Textures Bricks25; CC0, transformed by scikit-image.
- `grass.png`: linolafett, Grass-01 on DeviantArt; CC0, cropped by scikit-image.
- `gravel.png`: CC0Textures Gravel04; CC0, transformed by scikit-image.

Procedural scenes and modifications are generated by the checked-in script with
fixed parameters and seed. No game captures or benchmark scores are invented.
The photometric degradation experiment does not prove recovery of missing game detail.
