# SR.4 — single-frame inverse candidate

The working SR.3 prior is evaluated on a 7×7 HR tile with a 5×5 interior. Sixteen raw, pre-Focus observations constrain it. Forward operator: exact 5:4 pixel area and a mild symmetric [0.05,0.90,0.05] low-pass. The interior inverse C=(AᵀA+0.003I)⁻¹Aᵀ is generated offline, no runtime solver. Apply 0.75 times the luma correction, clamp to ±0.15 and retain alpha. No temporal history, one additional GPU dispatch and a 1280×800 RGBA8 target. Nonopaque tiles use the spatial prior. Nonfullscreen, incompatible surface/transfer, additional post effects, or allocation failure fall back to SR.3. GPU timing includes the inverse stage.

CPU experiment: approximate Focus, synthetic area and additional blur+area downsampling, 5 validation images and 3 held-out images (immunohistochemistry, page, Hubble deep field). RGB PSNR on held-out set: 32.0649 → 33.6150 dB; SSIM 0.92778 → 0.94124; luma high-frequency correlation 0.73138 → 0.79492. Relative HF RMS error 0.70090 → 0.62974. Validation RGB PSNR 35.7451 → 37.2174 dB. The prior matched-model oracle is not a GPU result. Steam Deck performance, mismatch robustness, motion and native-game fidelity remain unverified. Inverse correction can reduce excessive sharpening on already blurred input; it is not guaranteed to increase HF amplitude in every scene.

Test harness exercises the exact shader stage for constant input, correction of differing measured/prior values, and nonopaque-tile rejection. Run standard KEDAVRA workflow and package from pinned GFG branch. Graphics exposes Inverse SR or Spatial SR fallback. For testing disable look and AA effects; Focus is forced automatically.
