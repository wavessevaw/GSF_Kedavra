# GSF Kedavra 1.5.0

Развитие **Silk 1.4.0** на базе движка из GFG Extreme 3.2.2.

- Более чёткие детали при быстром, достоверно восстановленном движении: адаптивное уменьшение размытия в согласованных областях.
- Сохранена прежняя обработка неоднозначного движения и перекрытий.
- Без дополнительных GPU-проходов, текстурных выборок и буферов.

В воспроизводимом Vulkan-тесте быстрой панорамы: PSNR +3,68–4,20 дБ, средняя ошибка RGB примерно на 80% ниже. Обычный набор и тесты низкого исходного FPS проходят. Это программные измерения; аппаратная проверка Steam Deck не заявляется. Квадратные артефакты при сложных поворотах ниже 30 FPS остаются известным ограничением.

**Установка:** установить ZIP через Decky Loader, обновить Gamescope в Setup и перезагрузиться. Сохраните ZIP 1.4.0 для возврата.
