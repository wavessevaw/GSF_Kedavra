# GSF Kedavra 1.5.0

GSF Kedavra 1.5.0 develops the **Silk 1.4.0** engine used by GFG Extreme 3.2.2. This release focuses on keeping fine details sharper during fast motion while retaining the existing reconstruction for uncertain regions.

## What improved

- **Sharper fast motion.** The engine reduces its existing motion blur when the two reconstructed source samples agree, the motion estimate has a low matching error, and neighbouring motion vectors are consistent.
- **Conservative handling of difficult regions.** Areas with ambiguous motion, conflicting samples or inconsistent neighbouring vectors continue to use the previous reconstruction.
- **A small change to the GPU pipeline.** The improvement uses samples already available to the reconstruction shader. It adds no GPU passes, intermediate buffers or texture reads.
- **Existing engine behaviour is preserved.** Motion estimation, frame scheduling, generation modes and SDR/HDR support remain based on Silk.

The earlier experimental local colour-range clamp is not included in this release.

## Validation and measured results

In a reproducible 1280×800 synthetic fast-pan test running through the Vulkan engine, generated-frame PSNR improved by **3.68–4.20 dB**. Mean absolute RGB error was approximately **80% lower**; at the first ×3 intermediate phase, SSIM increased from **0.965 to 0.987**.

The normal and low-source-FPS software test suites passed, including checks for both ×3 intermediate frames, ×2, static content, HUD preservation, scene cuts and HDR. CI also passed scheduler tests, Decky tests, the Gamescope build and a runtime compatibility check against an older glibc.

These results describe the tested synthetic scenes. They are not measurements of performance or image quality in every game.

## Known limitations

Block-shaped artifacts can still appear during complex camera turns below 30 source FPS. Their reduction in the tested difficult scenes was small; this release does not claim to solve that problem.

Steam Deck GPU cost, power consumption, physical display pacing and input-to-photon latency have not been validated on hardware for this release. No additional texture reads does not mean zero additional shader cost.

## Installation and rollback

1. Download `GSF-Kedavra-1.5.0.zip` and optionally verify it against the supplied SHA256 file.
2. In Decky Loader, open **Settings → Developer → Install Plugin from ZIP**.
3. Install the ZIP, open Kedavra Setup and update/reinstall its Gamescope runtime.
4. Reboot when prompted and confirm that Setup reports the installed runtime matching the plugin.

Keep your previous working installer and settings backup. To roll back, use Setup to restore the stock Gamescope, reboot, then install the previous plugin and its runtime.
