# Эксперимент: три выборки фильтра по выровненной оси

**Решение: не внедрять по имеющимся данным.** На этом ПК выигрыш не обнаружен; переносить результат на Steam Deck нельзя.

Исходник: официальный v1.4.1, `5f22938b55f9853f764e927c847d9c1a8d9a8c04`. Экспериментальный shader: `599380fe167ebe09771b759b63ef88cd9c30e9fb`. При целой координате по одной оси пропускаются две выборки с нулевым весом; изменяется ветвление шейдера. Вещественная арифметика может округляться иначе.

На Windows PC, AMD Radeon(TM) Graphics, AMD proprietary driver 26.10.1: пять последовательных прогонов A/B/A/B/A, размер 1280×800, по 128 повторений с тремя прогревочными, существующий `kfg_vktest --scene pan --bench 128`. Сам benchmark генерирует сцену objects_hud. Из GPU timestamps отдельно взяты два warp, каждый показатель — сумма их медиан:

| Прогон | Сумма медиан двух warp, мс |
| --- | ---: |
| A: v1.4.1 | 2,380 |
| B: кандидат | 2,405 |
| A: v1.4.1 | 2,379 |
| B: кандидат | 2,406 |
| A: v1.4.1 | 2,380 |

Это короткая проверка одного искусственного сценария при неизвестной внешней нагрузке. Она не устанавливает результаты в играх, TDP, задержку ввода или производительность RADV и не доказывает причину различия. Данные в `windows-benchmark.json`; исходные журналы содержат поэтапные значения. В тесте v1.4.1 этап `global` ошибочно причисляется к генерации, поэтому таблица использует только строки `g1:warp` и `g2:warp`.

Проверка 16 синтетических кадров в пяти сценах (pan, objects_hud, occlusion, stairs, near_object): наибольшее различие — 13 пикселей из 1 024 000 в одном кадре, максимум 1 из 255 по каналу. Это лишь сравнение 8-битных изображений на данном драйвере, не гарантия точного совпадения HDR или других сцен. Данные в `windows-images.json`; воспроизведение: `run_windows_benchmark.py`, `run_windows_images.py` и [сборка теста](https://github.com/wavessevaw/GSF_Kedavra/actions/runs/40451751899).

При наличии Deck вариант можно повторно оценить на RADV с инструментами профилирования и длительным A/B/A. Дополнительная ветка может замедлять SIMD-группы, а компилятор и так может устранить нулевые вычисления. Релиз не изменён.
